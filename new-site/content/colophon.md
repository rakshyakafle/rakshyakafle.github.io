## Purpose

This website is about my hometown of Pokhara, Nepal. It highlights some of my favorite places, the best seasons to visit, and local food. The site was originally created with HTML and CSS and was later converted into a Hugo website.

## Technology & Tools

- Static Site Generator: Hugo
- Markup: HTML5 and Markdown
- Styling: Custom CSS3
- Templates: Hugo layouts and partials
- Editor: Sublime Text
- Version Control & Hosting: Git and GitHub Pages

## Typography & Assets

- Headings: Playfair Display
- Body Text: EB Garamond
- Images: Local images of Phewa Lake, Peace Pagoda, and Sarangkot
- Design inspired by the lakes and mountain scenery of Pokhara

## Hugo Structure

The website uses a custom Hugo theme called **classtheme**. The header and footer are shared using Hugo partials, while the CSS and images are stored in the static folder.
